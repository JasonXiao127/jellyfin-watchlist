Watchlist

This plugin treats each user's Jellyfin Favorites as their watchlist. Star a movie, series, or season anywhere in Jellyfin, and the plugin removes it from Favorites when the user completes it. There is no separate list or custom page: the native Favorites page is the watchlist.

How to use (works on web, mobile, and TV):
  1. Star a movie, series, or season with the ★ favorite button.
  2. Find it later on the Favorites page.
  3. Watch it normally. The plugin removes it from Favorites when complete.
  4. Star a finished item again to rewatch: if it is still fully watched, its played state is cleared. Re-adding an airing item just resumes tracking.
Favorites are shared with normal Jellyfin use. A favorite that was already complete when it was starred is kept, and re-starring a completed item keeps it again unless the plugin removed it (rewatch). Use the exempt tag or turn off automatic removal (movies, series, and/or seasons) if you use Favorites for things you want to keep.
Ended + fully watched waits until the series is marked Ended in metadata and every eligible episode is played. Catching up on an ongoing show does not remove it.
Caught up removes the series as soon as every currently available episode is played, even if more episodes are coming. This mode ignores the airing guard below.
Latest season watched removes the series when every episode of its newest season is played; earlier seasons are ignored. Unless still airing and the guard below is on.
When on, a complete series or season with unaired or announced future episodes stays in Favorites until those episodes air and are watched. Caught up mode is exempt and still removes mid-season. Re-adding an airing item never clears its played state.
A favorite movie is removed when it transitions to played. Movies that were already played when favorited are kept.
A favorite series is removed according to the completion mode above.
A favorited season is removed when every eligible episode in that season is played. A directly favorited season zero is evaluated literally even when specials are ignored for series. A season with unaired or announced future episodes stays until they air, unless the airing guard above is off.
When an item the plugin removed is added back to Favorites and it is still fully watched, clear its played state so you do not have to unmark everything manually. Only finished items are reset: re-adding an airing series or season never clears played state. Only the user who re-adds the item is reset. A re-added series is only reset when every eligible episode across all seasons is played; otherwise favorite a specific season. This clears played badges and resume positions.
When enabled, specials do not need to be watched before a series counts as complete. Latest-season mode always ignores season zero.
Only affects the Ended + fully watched mode. Leave this off if a missing status should keep the series on the list.
Movies, series, and seasons with this tag are never auto-removed. Leave empty to disable the exempt tag. Default: keep-favorite.
Real-time events handle playback completion. Reconciliation catches missed events and metadata changes, such as a series becoming Ended after it was watched. Turning this off also disables the Watchlist cleanup task below, including manual runs. You can run a scan on demand from Dashboard → Scheduled Tasks → Watchlist cleanup while it is on.
Useful for checking the configuration. The server log shows what would have been removed.
